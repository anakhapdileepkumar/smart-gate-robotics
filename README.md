# Smart Gate Robotics Project

## Overview
This project simulates an automated smart gate system using Arduino Uno, Ultrasonic Sensor, Servo Motor, and LED indicators.

The gate automatically opens when a vehicle is detected and closes when the path becomes clear.

---

## Features
- Vehicle detection using HC-SR04 ultrasonic sensor
- Automatic gate opening and closing
- LED blinking indication during gate movement
- Obstacle checking before gate closing
- Blockly custom block for gate control
- Frontend dashboard simulation

---

## Components Used
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- LED
- Resistor
